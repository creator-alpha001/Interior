# Stock photographs

Stand-ins until real project photography exists. Every file here is a free
photograph from Unsplash, used under the Unsplash License
(https://unsplash.com/license): free for commercial use, no attribution
required, not to be sold unaltered or used to build a competing photo service.

Only free-licence photos were chosen (`images.unsplash.com`); nothing here is
from Unsplash+.

`packages/ui/src/media.tsx` picks one per `ph:<trade>:<seed>` placeholder, by
seed. Its `photoPools` counts must match the files in each folder.

Each file is `https://images.unsplash.com/<id>`, resized to 1400px wide (2200px
for `hero/1`).
